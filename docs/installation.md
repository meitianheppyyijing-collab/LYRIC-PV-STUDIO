# Installation

1. Download `LYRIC_PV_STUDIO_v0_5_15_LRC_spacing_fix.py` from the repository.
2. Start Blender 5.2 or newer.
3. Open **Edit → Preferences → Add-ons**.
4. Select **Install from Disk…** and choose the downloaded Python file.
5. Enable **LYRIC PV STUDIO**.
6. In the 3D View, open the sidebar with `N` and look for the **Lyric PV** tab/panel.

## If the panel is missing

- Confirm the add-on is enabled in Preferences.
- Confirm the installed file is the v0.5.15 `.py` file from this repository.
- Open **Window → Toggle System Console** (Windows) and inspect any Python traceback produced during enablement.
- Disable and re-enable the add-on after correcting any reported error.

This guide describes installation; it does not claim that the add-on has been runtime-tested in every Blender environment.
