# Installation

1. Download the latest release package `lyric_pv_studio_vx.x.x.zip` from the Releases page (or zip the `lyric_pv_studio` folder from source).
2. Start Blender 5.2 or newer.
3. Open **Edit → Preferences → Add-ons**.
4. Select **Install from Disk…** and choose the downloaded `.zip` file.
5. Enable **LYRIC PV STUDIO**.
6. In the 3D View, open the sidebar with `N` and locate the **歌词PV** (Lyric PV) panel.

## If the panel is missing

- Confirm the add-on is enabled in Preferences.
- Confirm the installed archive contains the `lyric_pv_studio` directory with `__init__.py`.
- Open **Window → Toggle System Console** (Windows) to check for any Python tracebacks during registration.
- Try disabling and re-enabling the add-on.
