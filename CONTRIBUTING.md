# Contributing

Thank you for your interest in LYRIC PV STUDIO.

## Before proposing changes

- State the Blender version used (the current source targets Blender 5.2).
- Describe the steps to reproduce a problem and the expected versus actual result.
- Include relevant console output, screenshots, and a minimal test scene when possible.
- Keep changes focused and preserve existing project files and versioned source snapshots.

## Testing

Static checks are useful but do not replace testing inside Blender. Clearly label whether a change has only passed static checks or has also been exercised in Blender. Do not claim Blender runtime validation unless it was actually performed.

## Pull requests

Explain the motivation, summarize the changes, list tests performed, and note any known limitations. Avoid committing personal scenes, generated caches, or unrelated assets.
